# 📊 Calculator FAB

Kalkulator Floor Area Bersih untuk shift kerja Morning & Night.

## 🚀 Cara Pakai
Buka langsung di browser — tidak perlu install apapun.

## ✨ Fitur
- ⏰ Hitung FAB otomatis (Morning 9j45m / Night 9j50m / Jumat 8j)
- 🎫 Input ticket izin keluar dengan timer countdown
- ⏱ Notifikasi pengingat waktu kembali
- 🎨 7 tema warna
- 📊 Rekap lengkap + Export CSV + Print
- 💾 Backup & Restore data JSON
- 📶 Bekerja offline

## 📊 Rumus FAB
```
FAB = Durasi Kerja − Total CRout
Sholat/Kantin  → Jam Kembali − 30 menit
Toilet/Klinik  → Jam Kembali − 15 menit
```
